# Decisions — lobby lap

- **D1 Split.** New `features/lobby` owns players-in-slots, the settings menu and the join screen; `level-file` owns the level library; `match` stays the round. `pages/GamePage.tsx` composes them (lobby ⇄ match). Lobby depends on `level-file`, `level`, `match` (types + `applyLevelSettings`); nothing depends on lobby.
- **D2 Settings precedence.** Lobby settings become the tunables passed to `createGameState`; the level's settings apply on top inside it (one path, `applyLevelSettings`). Gravity multiplies (engine × lobby × level), so a level built for low gravity stays relatively low. A level's `matchDurationS` wins over the lobby's duration; the lobby shows "This level plays m:ss (set by the level)".
- **D3 Menu driven by the players' own controls** (common in local-multiplayer party games): a device without a slot joins with confirm (Space / Enter / pad A); joined devices move one shared cursor (up / down), change values (left / right), confirm a row, and leave with back (Q / Backspace / pad B). The pointer works on every row too; pointer clicks keep focus off buttons so Space / Enter stay with the players.
- **D4 Slots are fixed.** A player keeps their slot (colour + emblem) when others leave; a new joiner takes the first free slot. Empty slots map to `null` sources, so the sim's `joinSlots` never spawns them.
- **D5 Round end.** Jump = rematch (unchanged), back = lobby, both after `restartLockSeconds`. Lobby keeps players, level and settings.
- **D6 Built-in level manifest** is a TS constant (`BUILT_IN_LEVEL_FILES` in `level-file/services/levelFileSource.ts`) with a drift test against `public/levels/`, instead of a JSON file in `public/levels/` (that would need a `projectStructure.config.cjs` change). First entry = default level.
- **D7 Key autorepeat ignored** by the input reader: a key held when a screen opens (the press that started or ended the round) does not count until pressed again.
- **D8 Emblem geometry extracted** to `shared/utils/playerEmblem.ts` (+ `shared/services/emblemRenderer.ts` for Pixi): the lobby's SVG blob was the third copy (helmet, HUD chip). The HUD chip now uses the helmet proportions.
- **D9 Keyboard file picking.** The "Your level" row opens the file picker through `LevelImportControl`'s `pickerRef` (works from keyboard presses; browsers don't count gamepad presses as user activation, so pads use the pointer or drag-and-drop for files).
